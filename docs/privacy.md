# Privacy Policy

AgentSponsor prioritizes user privacy above all else.

## What We Collect
- **Telemetry Limits**: We only collect anonymized CLI usage statistics (command executed, duration, success/failure).
- **Session IDs**: Randomized UUIDs to track session duration without tying to identity.

## Zero Prompt/Code Collection Guarantee
We **NEVER** collect:
- Source code.
- File contents.
- Prompts passed to the AI.
- Environment variables or secrets.

All plugin code is open source and auditable.
