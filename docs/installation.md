# AgentSponsor Installation Guide

AgentSponsor plugin supports multiple operating systems.

## Prerequisites
- Antigravity CLI installed.
- Python 3.9+

## Cross-Platform Installation

### Linux / macOS
```bash
# Clone the repository
git clone https://github.com/example/agentsponsor.git
cd agentsponsor

# Install the plugin
python -m pip install -e .
```

### Windows
```powershell
# Clone the repository
git clone https://github.com/example/agentsponsor.git
cd agentsponsor

# Install the plugin
python -m pip install -e .
```

## Verifying Installation
Run `agy --help` and verify that the `sponsor` commands are available.
