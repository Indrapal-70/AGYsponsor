# 48-Hour Release Checklist

## T-48 Hours: Staging & QA
- [ ] Deploy backend to Staging environment.
- [ ] Run end-to-end integration tests.
- [ ] Verify Supabase RLS policies and database migrations.

## T-24 Hours: Production Deployment
- [ ] Deploy backend to Production.
- [ ] Seed initial demo advertiser and campaign data.
- [ ] Perform security audit and finalize Privacy Policy.

## T-0 Hours: Launch
- [ ] Publish frontend dashboard.
- [ ] Publish Antigravity plugin to PyPI.
- [ ] Announce release on social channels and developer communities.

## Post-Launch: Verification
- [ ] Monitor error rates in Sentry.
- [ ] Verify impression telemetry is correctly tracked.
- [ ] Ensure non-blocking behavior during high load.
