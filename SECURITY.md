# Security Policy

## Reporting Security Issues

We take the security of AgentSponsor seriously.

If you discover a security vulnerability or security-related issue, please report it privately rather than disclosing it publicly.

Please report all security vulnerabilities to:
`security@example.com` [PLACEHOLDER - Replace before public release]

Include as much detail as possible to help us reproduce and address the issue, including:
- Steps to reproduce
- Affected versions or endpoints
- Potential impact

We will acknowledge receipt of your report and provide updates as we work to resolve the issue.

Please do not open public GitHub issues for security vulnerabilities.
